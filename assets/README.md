# 图片与视觉素材约定

本目录用于保存教程截图、示意图和后续网站视觉素材。

## 目录建议

```text
assets/
├─ agents/       # 各 Agent 的界面与体验截图
├─ cases/        # 真实案例过程截图
├─ diagrams/     # 流程图和架构图
└─ branding/     # 后续的网站、海报和演示视觉
```

实际有素材时再创建对应子目录。

## 文件命名

建议使用：

```text
产品或章节-场景-步骤-日期.ext
```

示例：

```text
codex-first-task-01-20260811.png
hermes-permission-screen-02-20260811.png
harness-validation-loop-v1.svg
```

## 截图检查

- [ ] 已移除账号、头像、邮箱、路径、密钥和真实业务数据；
- [ ] 截图只保留与讲解有关的区域；
- [ ] 图中标注与正文步骤一致；
- [ ] 正文包含清晰图注和替代文字；
- [ ] 记录了截图日期和产品环境；
- [ ] 确认截图使用符合对应产品的条款与合理引用范围。
