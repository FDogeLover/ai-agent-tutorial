# 项目总结

## 项目目标

制作一套面向零基础或计算机基础较弱读者的 AI Agent 桌面版教程。教程的核心任务不是罗列功能，而是帮助读者完成三件事：认识什么是 Agent、根据自己的场景选择合适的工具、通过真实任务建立稳定的工作流。在此基础上，读者逐步理解模板、Skill 和 Harness 等进阶概念。

教程覆盖七款桌面 Agent 产品，分为四类入门认识：

| 分组 | 产品 | 特征 |
|------|------|------|
| 海外闭源托管型 | Claude、Codex | 综合能力强，账号和地区可用性需关注 |
| 国内综合型 | TraeWork（中国版）、WorkBuddy | 面向国内用户，登录和使用门槛较低 |
| 代码优先型 | Qoder（中国版）、ZCode（中国版） | 以代码项目为主要场景，兼有任务管理 |
| 开源自主型 | Hermes Desktop | GUI 成熟，但模型配置和维护需要计算机基础 |

Qoder、TraeWork、ZCode 只采用中国版资料、账号和客户端，不混入国际版或旧版内容。教程不把 CLI 或 TUI 作为新手主入口。

## 目标读者

材料中描述了四类典型读者画像：

- **用过聊天式 AI 但没用过 Agent 的人**——希望处理工作、生活、内容或项目事务，但不熟悉命令行，更适合从桌面图形界面开始。
- **已经零散使用 Agent 的人**——能完成单次任务，但缺乏稳定工作流，需要系统化指引。
- **没有编程基础的初学者**——对终端、Git、模型供应商等概念感到紧张，最关心哪些操作安全、哪些会删除文件、花钱或泄露内容。
- **有一定经验的进阶用户**——需要 Skill 和 Harness 的真实案例，包括失败过程和调整方法，而不只是最终成果展示。

试读反馈（模拟样本，非真实用户研究）还揭示了几个共性需求：免费版能用多久、Credits/Token/API Key 的区别、产品太多不知先装哪个、修改代码后如何确认没改坏、账号不稳定时的申诉和替代方案。

## 内容边界

### 纳入范围

- 七款桌面 Agent 的安装、登录和基础操作；
- 以统一基准任务为线索的产品体验和对比；
- 模板、Skill、Harness 和多 Agent 协作的进阶讲解；
- 价格、Credits、账号可用性和申诉流程的集中说明；
- 面向新手的安全操作指引（哪些按钮可以放心点，哪些需要谨慎）。

### 排除范围

- CLI 或 TUI 作为主入口的教学路径；
- 脱离具体场景的产品总排名；
- 从单个账号封禁案例推导普遍封号率；
- 部署网站和视觉设计的最终方案（暂未决定，但页面文件名、更新时间、图片替代文字等规范应提前统一）。

### 内容原则

材料明确了几条写作原则：

- 先说适合谁和解决什么问题，再讲功能；
- 区分官方事实、实际测试、作者经历和待验证判断；
- 所有易变信息标注日期、地区和产品线；
- 删除、支付、发送、发布和扩大权限需要人工决定，不由教程自动执行。
