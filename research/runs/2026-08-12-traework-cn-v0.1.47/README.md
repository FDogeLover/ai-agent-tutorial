# TraeWork 中国版 v0.1.47 共同基准任务

## 目的

这是七款桌面 Agent 的共同基准第一轮，用于观察 TraeWork 中国版在默认模式、零额外指导条件下的端到端交付体验。

本次不比较底层模型跑分，重点记录成品、预览、变更展示、过程可控性、用时和 Credits。不得用 Trae CN 代码开发环境替代 TraeWork 中国版。
