# AI Agent 零基础教程：项目总结

> 整理日期：2026-08-12  
> 依据范围：仅使用 `input` 文件夹内材料；未联网补充事实。

## 1. 项目目标

制作一套从桌面图形界面起步的 AI Agent 教程，帮助零基础或计算机基础较弱的读者：

1. 建立对 Agent 的基本认识，理解它与普通聊天式 AI 的使用差异；
2. 根据任务、地区可用性、成本、风险和学习门槛选择工具；
3. 在清楚文件位置、执行进度和权限边界的前提下完成真实小任务；
4. 学会检查结果、发现错误、恢复失败，而不只看“生成成功”；
5. 逐步理解模板、Skill、Harness、多 Agent 等进阶工作方式。

教程强调“先完成一个小任务，再解释抽象概念”，不以功能罗列或脱离场景的总排名为主线。

## 2. 目标读者

- 用过聊天式 AI，但没有使用过能操作文件和工具的 Agent；
- 不熟悉命令行，更适合从 Windows 桌面图形界面开始；
- 希望处理办公、生活、内容或项目事务；
- 准备学习编程，但还不知道如何确认 Agent 没有改坏代码；
- 已零散使用多个 Agent，希望形成稳定、可复用、可恢复的工作流；
- 关注地区可用性、付费风险、账号稳定性和替代方案的读者。

`02-reader-feedback.md` 中的读者反馈是模拟样本，只能用于检查教程是否覆盖常见疑问，不能作为真实用户研究结论。

## 3. 内容边界

### 3.1 纳入范围

- 产品：Claude 桌面版、Codex 桌面版、TraeWork 中国版、WorkBuddy、Qoder 中国版、ZCode 中国版、Hermes Desktop；
- 入门方式：以桌面 GUI 为主；
- 基础主题：工具选择、文件与项目组织、任务状态、权限与高风险动作、成本相关术语；
- 实践主题：统一任务、结果检查、失败恢复、代码修改验证；
- 进阶主题：模板、Skill、Harness、多 Agent；
- 编辑要求：真实截图须解释入口、操作、结果或风险；页面文件名、更新时间和图片替代文字须统一；
- 事实标注：区分官方事实、实际测试、作者经历和待验证判断；易变信息标注日期、地区和产品线。

### 3.2 明确排除或限制

- 不把 CLI 或 TUI 作为新手主入口；
- Qoder、TraeWork、ZCode 只使用中国版资料、账号和客户端；
- Qoder 中国版不得混入国际版或 QoderWork CN 的旧学生活动；
- 不做脱离使用场景的总排名；
- 不用作者单个 Claude 账号封禁案例推导普遍封号率；
- 不把当日可见积分或活动写成永久权益；
- 删除、支付、发送、公开发布和扩大权限等动作必须由人工决定；
- 网站技术、视觉设计与部署尚未决定，不应在正文中假定方案。

## 4. 产品分组基线

材料中的 `interface-map.svg` 用四类帮助读者建立第一印象，明确说明分组不代表能力排名：

| 分组 | 产品 |
|---|---|
| 海外闭源托管型综合 Agent | Claude、Codex |
| 国内综合型 Agent | TraeWork、WorkBuddy |
| 代码优先型 Agent | Qoder、ZCode |
| 开源自主型 Agent | Hermes Desktop |

该分组可作为选型章节的导航，但具体适用性仍须由统一实测和地区可用性核对支持。
