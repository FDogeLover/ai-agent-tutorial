# Agent 实测运行记录

本目录保存七款桌面 Agent 的实际测试副本、过程记录、交付物和脱敏证据。

## 目录命名

```text
YYYY-MM-DD-产品名-客户端版本/
```

每次运行至少包含：

- `input/`：从冻结基准包复制的只读材料；
- `output/`：Agent 实际创建的指定交付文件；
- `workbuddy-prompt.md` 或对应产品提示文件：当次原样输入；
- `run-manifest.md`：版本、账号状态、模式、权限和测试条件；
- `run-record.md`：时间线、人工介入、问题和恢复；
- `acceptance-checklist.md`：逐项验收；
- `evidence/screenshots/`：完成脱敏的截图和图注。

## 原则

- 第一次运行使用默认模式和零额外指导；
- 不修改已开始运行的输入材料；
- 优化提示后的第二轮另建目录；
- 账号名称、历史任务、项目路径和额度截图必须脱敏；
- 产品无法完成的步骤如实记为限制，不由测试者代做后记成成功。
