# 新手试读反馈样本

> 说明：以下是用于基准测试的模拟反馈，不是真实用户研究结论。

## 读者 A：普通办公用户

“我最关心免费版能做多久，不太理解 Credits、Token 和 API Key 的区别。产品很多，如果每个都介绍十几项功能，我还是不知道先装哪个。”

## 读者 B：没有编程基础

“看到终端、Git、模型供应商就会紧张。我希望先知道哪些按钮可以放心点，哪些操作会删除文件、花钱或把内容发出去。”

## 读者 C：准备学习编程

“我想知道 Qoder、ZCode 和 Codex 修改代码后，怎么确认没有改坏。只展示生成代码对我帮助不大。”

## 读者 D：使用过多个 Agent

“我需要 Skill 和 Harness 的真实案例，最好能看到第一次设计为什么失败，以及后来怎样调整，而不是只给最终目录。”

## 读者 E：重视稳定性

“如果软件在我的地区不能稳定登录，或者付费后账号出问题，功能再强也没法作为主力工具。希望教程把申诉和替代方案说清楚。”
