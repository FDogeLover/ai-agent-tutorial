## 一、项目目标

制作一套面向**零基础或计算机基础较弱读者**的 AI Agent 桌面版教程，帮助读者：

1. 认识什么是能操作文件和工具的桌面 Agent（区别于聊天式 AI）；
2. 在七款产品中做出适合自己的选择；
3. 从第一个真实小任务开始，逐步建立稳定工作流；
4. 理解模板（Template）、技能（Skill）和运行框架（Harness）等进阶概念。

教程不做脱离场景的总排名，不把单个账号封禁案例推导为普遍封号率。所有易变信息（价格、Credits、活动、账号可用性）需标注日期、地区和产品线。

## 二、目标读者

| 读者画像 | 核心需求 |
|---|---|
| 用过聊天式 AI，没用过能操作文件和工具的 Agent | 知道 Agent 和聊天机器人的区别，知道先装哪个 |
| 不熟悉命令行，更适合从桌面图形界面开始 | 通过 GUI 完成任务，避免终端操作 |
| 希望处理工作、生活、内容或项目事务 | 看到真实场景而非纯功能罗列 |
| 已零散使用 Agent，希望建立稳定工作流 | 系统化理解模板、Skill、Harness 和多 Agent 协作 |

来自试读反馈的补充痛点：

- **读者 A（普通办公）**：关心免费版能用多久，分不清 Credits / Token / API Key，产品太多不知先装哪个。
- **读者 B（无编程基础）**：对终端、Git、模型供应商紧张，想知道哪些按钮可放心点、哪些操作会删文件、花钱或外发。
- **读者 C（准备学编程）**：想知道修改代码后怎么确认没改坏，而不只是看生成代码。
- **读者 D（用过多个 Agent）**：需要 Skill 和 Harness 的真实案例，想看到第一次设计为什么失败及如何调整。
- **读者 E（重视稳定性）**：关心本地区能否稳定登录、付费后账号出问题的申诉和替代方案。

## 三、内容边界

### 涵盖范围

- **七款桌面 Agent 产品**：

  | 分组 | 产品 | 地区/产品线约束 |
  |---|---|---|
  | 海外闭源托管型综合 Agent | Claude、Codex | Windows 桌面版 |
  | 国内综合型 Agent | TraeWork、WorkBuddy | 仅中国版 |
  | 代码优先型 Agent | Qoder、ZCode | 仅中国版 |
  | 开源自主型 Agent | Hermes Desktop | 开源桌面版 |

  > 分组来自 `input/images/interface-map.svg`，用于建立第一印象，不代表能力排名。

- **新手主入口**：桌面图形界面（GUI），不以 CLI 或 TUI 为新手主入口。
- **内容层次**：先完成一个小任务 → 再讲模板 → 再讲 Skill → 再讲 Harness 和多 Agent。
- **截图要求**：截图需解释入口、操作、结果或风险，不能只作装饰。

### 不涵盖范围

- 不做脱离场景的总排名。
- 不把 CLI / TUI 作为新手主入口。
- Qoder、TraeWork、ZCode 不混入国际版或旧版资料（如 QoderWork CN 旧学生活动）。
- 不自行编造任何缺失事实（如 Claude 封号原因）。

### 内容原则

- 先说适合谁和解决什么问题，再讲功能；
- 区分官方事实、实际测试、作者经历和待验证判断；
- 删除、支付、发送、发布和扩大权限需要人工决定。
