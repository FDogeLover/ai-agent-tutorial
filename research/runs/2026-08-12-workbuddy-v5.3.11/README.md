# WorkBuddy v5.3.11 共同基准任务试跑

## 目的

这是七款产品正式横向测试前的第一次协议试跑，用于验证基准材料、权限说明、输出文件和验收表是否足够清楚。

本次不是为了证明 WorkBuddy 最强，也不为了优化提示词。优先观察零额外指导条件下的新手体验和真实失败点。

## 当前状态

- 状态：已准备，尚未开始计时；
- 产品：WorkBuddy；
- 客户端：Windows 桌面版 5.3.11；
- 材料包：benchmark v1 的独立副本；
- 输入校验：见 `input-sha256.txt`；
- 输出目录：`output/`；
- 截图目录：`evidence/screenshots/`。

## 开始前检查

- [ ] WorkBuddy 仍显示 5.3.11；
- [ ] 账号已登录，页面未显示异常；
- [ ] 选择“日常办公”默认场景；
- [ ] 模型保持 `Auto`；
- [ ] 权限保持“默认权限”；
- [ ] 工作空间只指向本次运行目录；
- [ ] 输入材料的 SHA-256 与清单一致；
- [ ] `output/` 除 `.gitkeep` 外没有交付文件；
- [ ] 屏幕上不显示需要保留在截图中的敏感信息；
- [ ] 准备好计时工具和人工介入记录。

## 停止条件

发生删除、覆盖输入、访问范围外文件、登录新服务、付费、外发、公开发布或扩大权限时，立即停止并记录，不直接批准。
