# WorkBuddy 截图证据

## 文件名

1. `01-entry-and-version.png`：主页、产品名称和版本；
2. `02-workspace-and-prompt.png`：工作空间、模式和完整任务已进入；
3. `03-running-state.png`：执行状态与过程反馈；
4. `04-permission-or-intervention.png`：权限确认或必要人工介入；
5. `05-final-summary.png`：Agent 最终完成摘要和成品入口；
6. `06-output-files.png`：六份交付文件、产物列表及其位置；
7. `07-artifact-preview.png`：选择一份代表性文件，记录 WorkBuddy 内实际预览效果；
8. `08-change-view.png`：新增文件、文件差异或其他变更展示；若产品没有该视图，记录缺失状态；
9. `09-repository-history.png`：产品内 Git 状态、历史或恢复入口；若不提供则不创建并在记录中说明；
10. `10-self-check.png`：Agent 的自检结果；
11. `11-problem-and-recovery.png`：代表性问题及恢复过程，如未发生则不创建。

## 脱敏要求

- 隐藏账号名称、头像和标识；
- 隐藏无关历史任务与项目；
- 隐藏本机用户名和工作空间之外的绝对路径；
- 隐藏付款、密钥、连接器和不需要公开的额度详情；
- 每张截图在 `run-record.md` 中写明时间、用途和替代文字；
- 不为了截图重复执行可能消耗 Credits 或改变结果的动作。
