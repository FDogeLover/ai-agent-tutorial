# 03 教程目录（提案）

> 说明：项目说明称"教程目录已完成"，但 `input/` 中未包含既有目录文件（见 02-C3）。本目录为**基于全部输入材料重建的提案**，需与既有目录合并、由作者确认后生效。
>
> 目录设计依据：
> - 内容原则"先小任务、后概念"（01-notes：先完成一个小任务，再讲模板、Skill、Harness 和多 Agent）；
> - 读者画像四类与模拟反馈五位的诉求（A 免费额度与术语、B 安全按钮、C 验证代码、D 失败案例、E 申诉与替代方案）；
> - 四类产品分组图（分组用于入门，不代表排名）；
> - 易变信息集中维护、统一文件名/更新时间/图片替代文字的要求。
>
> 编号规则：`0X` 为章节号，`0X.Y` 为小节号。产品参考页按分组顺序排列。

## 第 0 部分 开始之前

- 0.1 本教程适合谁（四类读者画像；新手最先遇到的三个问题：选哪个软件、文件放哪里、Agent 做到哪一步）
- 0.2 怎么读这本教程（先做任务、后讲概念；哪些章节可以跳读）
- 0.3 需要准备什么（一台 Windows 电脑、网络、可选账号；不需要命令行）
- 0.4 安全约定（删除、支付、发送、发布、扩大权限前先问自己；教程中哪些操作需要人工决定）

## 第 1 部分 认识 AI Agent

- 1.1 Agent 能做什么：操作文件、运行工具、完成多步任务
- 1.2 Agent 与聊天式 AI 的区别
- 1.3 常见术语速览：模型、对话、任务、项目、工作区、模板、Skill、Harness
- 1.4 新手常见困惑：文件放在哪里、Agent 做到哪一步算完成、出错会不会破坏文件

## 第 2 部分 第一次选择：哪款适合你

- 2.1 四种入门分组（分组只为建立第一印象，不代表能力排名）
- 2.2 海外综合型：Claude、Codex
- 2.3 国内综合型：TraeWork、WorkBuddy
- 2.4 代码优先型：Qoder、ZCode
- 2.5 开源自主型：Hermes Desktop（成熟 GUI，但模型、环境和维护仍需计算机基础）
- 2.6 按需决策表（按事务类型：工作 / 生活 / 内容 / 代码；按经验：零基础 / 用过聊天 AI / 用过 Agent）
- 2.7 每款产品"先装哪个"的最小判断路径（避免逐一罗列十几项功能）

## 第 3 部分 完成第一件真实任务

- 3.1 统一体验模板：任务从哪里开始、到哪里结束
- 3.2 第一个小任务：整理一份文件夹 / 生成一份项目总结（以共同基准任务为示例素材）
- 3.3 工作区与边界：哪些文件可读、哪些可写（只读输入、写入输出）
- 3.4 看懂 Agent 做到哪一步：日志、结果、交付物、自检清单
- 3.5 出错了怎么办：撤销、恢复、重试；引出"一次失败与恢复"的真实过程
- 3.6 完成与归档：页面文件名、更新时间、图片替代文字的规范（提前统一）

## 第 4 部分 模板：把任务固定下来

- 4.1 什么是模板、为什么新手需要它
- 4.2 模板的组成：目标、读者、边界、交付物、自检
- 4.3 三份通用模板示例（项目总结、信息缺口、写作计划 / 待办 / 自检）
- 4.4 如何修改模板而不改坏流程

## 第 5 部分 Skill：让 Agent 学会专业做法

- 5.1 什么是 Skill
- 5.2 真实案例：一个 Skill 的第一次设计为什么失败（含失败过程还原）
- 5.3 调整思路与第二次成功（迭代前后对比）
- 5.4 何时自己写 Skill、何时用现成的

## 第 6 部分 Harness：安全与权限

- 6.1 为什么需要 Harness（不只画架构图，用一次失败和恢复说明它解决了什么问题）
- 6.2 只读与写入边界、权限模式
- 6.3 哪些按钮可以放心点，哪些会删除文件、花钱或把内容发出去（逐产品安全操作指南）
- 6.4 人工决策边界：删除、支付、发送、发布前必须停下来

## 第 7 部分 验证：怎么确认没改坏

- 7.1 查看变更差异（diff）：改了什么、改在哪
- 7.2 试运行与测试：运行前先检查
- 7.3 代码任务的验证流程（Qoder、ZCode、Codex 示例）
- 7.4 非代码任务如何验证（文件、表格、文档）

## 第 8 部分 多 Agent 与自动化

- 8.1 多 Agent 协作：把大任务拆成子任务
- 8.2 自动化与定时任务
- 8.3 什么时候值得用自动化、什么时候手动更快

## 第 9 部分 账号、费用与稳定性

- 9.1 免费版能用多久：订阅与 Credits 概览（注明核对日期）
- 9.2 Credits、Token、API Key 的区别
- 9.3 付费前需要知道的事（活动、积分、地区差异；WorkBuddy 每日积分不视为永久权益）
- 9.4 账号出问题怎么办：申诉渠道与替代方案
- 9.5 地区可用性与登录稳定性（个案不推广为普遍结论）

## 第 10 部分 七款产品参考页（按分组排列）

- 10.1 海外综合型：Claude（含作者账号事件的口径说明，待作者决定）
- 10.2 海外综合型：Codex（含 Windows 清单显示 ChatGPT 的待核对说明）
- 10.3 国内综合型：TraeWork（Work / Code / Design 三模式）
- 10.4 国内综合型：WorkBuddy（办公、代码、设计场景；助理、项目、技能、自动化、资料库）
- 10.5 代码优先型：Qoder（Quest 为主要任务单位；不混入国际版 / QoderWork CN）
- 10.6 代码优先型：ZCode（分组、项目、自动化、技能、权限、模型选择）
- 10.7 开源自主型：Hermes Desktop（Skills、文件树、终端；门槛说明）
- 10.8 每款参考页的统一结构（适合谁 → 界面地图 → 安装与首次启动 → 第一个任务 → 安全注意事项 → 常见问题 → 核对日期）
