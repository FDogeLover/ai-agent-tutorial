# Hermes Desktop v0.17.0 共同基准任务

## 目的

这是桌面 Agent 共同基准第一轮，用于观察 Hermes Desktop 在现有可用模型配置、零额外任务指导条件下的端到端交付体验。

本次不比较底层模型跑分，重点记录成品、预览、变更展示、过程可控性、总用时和外部 API 成本。由于 Hermes 是开源自主型产品，另行观察 Provider、模型、环境、权限和维护责任对新手的影响。
