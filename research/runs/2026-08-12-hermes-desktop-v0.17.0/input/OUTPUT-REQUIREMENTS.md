# 统一任务与交付要求

请阅读当前 `input` 文件夹中的全部材料，在不联网补充事实、不覆盖原始文件的前提下完成以下工作：

1. 总结项目目标、目标读者、内容边界和当前进度；
2. 找出材料中缺失、过期、来源不清或仍需作者决定的信息；
3. 整理一份层级清楚的教程目录；
4. 制定结构化写作计划，标明优先级和前后依赖；
5. 创建一份可以逐项勾选的待办清单；
6. 将结果保存到与 `input` 同级的 `output` 文件夹；
7. 完成后按交付清单自检，并在最终回复中列出交付文件、未解决问题和需要人工复核的内容。

## 指定交付文件

- `01-project-summary.md`
- `02-information-gaps.md`
- `03-tutorial-outline.md`
- `04-writing-plan.md`
- `05-todo.md`
- `06-self-check.md`

## 权限边界

- 可以读取 `input` 中的文件，并在 `output` 中新建或修改交付文件；
- 不得修改、移动或删除 `input` 中的原始材料；
- 不得访问其他个人文件；
- 不得联网补充事实、登录其他服务、发送消息、公开发布或购买服务；
- 不确定的信息标记为“待确认”，不要自行编造；
- 如需扩大权限，请停止并说明原因。
