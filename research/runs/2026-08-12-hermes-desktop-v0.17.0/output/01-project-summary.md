## 1. 项目目标

制作一套**面向零基础或计算机基础较弱读者**的 **AI Agent 桌面版教程**，帮助读者：

1. **认识 Agent**——理解 Agent 与聊天式 AI 的区别（能操作文件与工具）；
2. **选择工具**——在七款桌面 Agent 中找到适合自己的一两款；
3. **完成真实任务**——从第一个小任务开始上手，知道文件放哪里、Agent 做到哪一步、如何确认结果；
4. **逐步理解进阶概念**——先完成小任务，再讲模板、Skill、Harness 与多 Agent，让概念落地而不是只给目录或架构图。

教程同时承担一份“事实分级”责任：区分官方事实、实际测试、作者经历和待验证判断，不做脱离场景的总排名。

## 2. 目标读者

材料中定义的四类读者（`00-project-brief.md`）：

| 读者类型 | 特征 | 主要诉求 |
|---|---|---|
| A. 聊天 AI 用户 | 用过聊天式 AI，没用过能操作文件和工具的 Agent | 理解 Agent 能做什么；免费版能用多久；Credits / Token / API Key 是什么 |
| B. 事务型用户 | 希望处理工作、生活、内容或项目事务 | 不碰命令行，从图形界面开始；知道哪些操作安全、哪些会删文件/花钱/外发内容 |
| C. 弱基础用户 | 不熟悉命令行、Git、模型供应商 | 先装哪个、先点哪个；害怕终端和术语 |
| D. 进阶新手 | 已零散使用 Agent，希望建立稳定工作流 | 需要 Skill / Harness 的真实失败—调整案例；需要代码改动后的验证方法 |

> ⚠️ 注意：`02-reader-feedback.md` 中的五位读者（A–E）为**模拟反馈，用于基准测试，不是真实用户研究结论**（文件开头已声明）。教程正式引用时需注明或另做真实调研（待作者决定）。

## 3. 产品范围与分类

**范围内（共 7 款桌面 Agent）**：

- 海外闭源托管型综合 Agent：**Claude**（Windows 桌面版）、**Codex**（OpenAI.Codex Windows 包）

## 5. 内容原则（写作时必须遵守）

1. **先讲适合谁、解决什么问题，再讲功能**；
2. **区分官方事实 / 实际测试 / 作者经历 / 待验证判断**四类事实来源；
3. **不做脱离场景的总排名**；
4. **不把单个账号封禁案例推导为普遍封号率**（如作者 Claude 账号被封，不得外推）；
5. **所有易变信息标注日期、地区和产品线**（价格、Credits、活动、账号可用性等应集中维护）；
6. **删除、支付、发送、发布和扩大权限类操作需要人工决定**；
7. 教学顺序：**先完成一个小任务，再讲模板、Skill、Harness 和多 Agent**；
8. **Harness 不能只画架构图**，要通过一次失败和恢复说明它解决了什么问题；
9. 页面文件名、更新时间、图片替代文字**提前统一**（具体规范值待确认，见信息缺口）。
