# 项目总结

> 基于 input 文件夹中全部材料整理，未联网补充事实。整理日期：2026-08-12。

## 项目目标

制作一套面向零基础或计算机基础较弱读者的 **AI Agent 桌面版教程**。教程要帮助读者完成三件事：认识 Agent 是什么、选择合适自己的工具、用 Agent 完成真实任务，并在此基础上逐步理解模板（Template）、Skill 和 Harness 等进阶概念。

项目强调"从真实问题出发，而不是从功能列表出发"——先让读者在一个具体场景中完成一个小任务，再引入抽象概念。教程还需要通过一次"失败与恢复"的过程来说明 Harness 等机制到底解决了什么问题，而不是只画架构图。

## 目标读者

教程面向以下特征的读者：

- 用过聊天式 AI（如 ChatGPT、Claude 网页版），但没有使用过能操作本地文件和调用工具的桌面 Agent；
- 希望用 Agent 处理工作、生活、内容创作或项目管理中的真实事务；
- 不熟悉命令行、Git 或终端操作，更适合从桌面图形界面入手；
- 已经零散使用过 Agent，但尚未建立稳定、可复现的工作流。

材料中附带了五份模拟读者反馈（读者 A–E），代表了普通办公用户、无编程基础者、准备学编程者、多 Agent 使用者和重视稳定性者五类人群。需要注意的是，这些反馈明确标注为"基准测试的模拟反馈，不是真实用户研究结论"。

## 内容范围与边界

### 产品范围

教程覆盖七款桌面 Agent 产品，分为四类：

- **海外闭源托管型综合 Agent**：Claude 桌面版（Windows）、Codex 桌面版（OpenAI）
- **国内综合型 Agent**：TraeWork 中国版、WorkBuddy 桌面版
- **代码优先型 Agent**：Qoder 中国版、ZCode 中国版
- **开源自主型 Agent**：Hermes Desktop

### 地区与版本约束

Qoder、TraeWork、ZCode 三款产品只采用中国版资料、账号和客户端，不得混入国际版或其他产品线（例如 Qoder CN 不得混入 QoderWork CN 的旧学生活动，也不得混入 Qoder 国际版）。

### 界面入口约束

教程不把 CLI（命令行界面）或 TUI（终端用户界面）作为新手主入口，所有产品优先从 GUI（图形界面）讲起。

### 内容原则

- 先说"适合谁、解决什么问题"，再讲功能；
- 区分官方事实、实际测试、作者经历和待验证判断；
- 不做脱离场景的总排名；
- 不把单个账号封禁案例推导为普遍封号率；
- 所有易变信息（价格、Credits、活动、账号可用性）标注日期、地区和产品线；
- 涉及删除、支付、发送、发布和扩大权限的操作需要人工决定后再写入。
