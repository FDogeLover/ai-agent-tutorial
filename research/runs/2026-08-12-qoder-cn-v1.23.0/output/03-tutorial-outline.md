# 教程目录

> 面向零基础读者的 AI Agent 桌面版教程。层级结构为"部分 → 章 → 节"，每章附简要说明。
> 遵循内容原则：先说适合谁和解决什么问题，再讲功能；区分信息来源；标注易变信息。

---

## 第一部分：认识 AI Agent

### 第 1 章 什么是 AI Agent

- **1.1 从聊天 AI 到 Agent：有什么不同**
  解释聊天式 AI 只能对话，而 Agent 能操作文件、使用工具、完成任务。用读者已熟悉的聊天 AI 经验作为起点。
- **1.2 Agent 能帮你做什么**
  按工作、生活、内容创作、代码项目四个场景举例，让读者建立具体预期。
- **1.3 本教程适合谁、不适合谁**
  明确读者画像（零基础、GUI 优先、桌面版为主），说明教程不覆盖 CLI/TUI 和国际版。

### 第 2 章 七款桌面 Agent 一览

- **2.1 四类分组：海外综合、国内综合、代码优先、开源自主**
  对应 `interface-map.svg` 中的分组，帮助读者建立第一印象。强调分组不代表能力排名。
- **2.2 每款产品一句话定位**
  Claude、Codex、TraeWork、WorkBuddy、Qoder CN、ZCode CN、Hermes Desktop 各用一句话概括核心特点。
- **2.3 如何选择第一款**
  根据读者的使用场景（办公 / 无编程基础 / 学编程 / 多 Agent 经验 / 重视稳定性）给出选择建议。

## 第二部分：安装与准备

### 第 3 章 下载、安装与账号

- **3.1 从哪里下载、如何确认安全**
  每款产品的官方下载渠道和验证方式。
- **3.2 注册、登录与订阅方案**
  注册流程、免费额度、付费方案。易变信息标注日期和地区。
- **3.3 账号安全与地区注意事项**
  登录稳定性、账号封禁风险（区分官方事实与个案）、申诉途径。不把个案推导为普遍风险。

### 第 4 章 界面导览与基础设置

- **4.1 主界面有哪些区域**
  逐产品介绍主窗口布局，配合真实截图，解释每个区域的入口和作用。
- **4.2 哪些按钮可以放心点，哪些操作不可逆**
  对应读者 B 的反馈，明确标注安全操作（如对话、预览）与风险操作（如删除文件、花钱、发送内容）。
- **4.3 Credits、Token 和 API Key 是什么**
  对应读者 A 的反馈，用通俗语言解释三个概念的区别和关系。

## 第三部分：完成第一个任务

### 第 5 章 从零开始一个小任务

- **5.1 选择任务：工作、生活、内容还是代码**
  提供 2-3 个候选任务（具体选择待作者决定，见 D-02），让读者跟随操作。
- **5.2 输入提示、观察过程、检查结果**
  演示如何向 Agent 下达指令，如何观察执行过程，如何验证结果是否正确。
- **5.3 如果结果不对：查看、调整、重试**
  教读者理解 Agent 的输出，学会调整提示和重新尝试，而不是直接放弃。

### 第 6 章 文件管理：Agent 在哪里操作、改了什么

- **6.1 工作空间在哪里、文件放在哪里**
  解释工作空间的概念，帮助读者找到 Agent 创建和修改的文件。
- **6.2 如何确认 Agent 没有改坏东西**
  对应读者 C 的反馈，介绍变更查看、对比和恢复的基本方法。
- **6.3 备份与回退**
  教读者在 Agent 操作前做好备份，操作后能回退到安全状态。

## 第四部分：理解模板与 Skill

### 第 7 章 模板：让 Agent 按固定方式工作

- **7.1 什么是模板、为什么需要模板**
  从第 5 章的手动提示过渡到模板的概念——把反复使用的提示固化下来。
- **7.2 使用现有模板**
  演示如何在不同产品中找到和使用已有的模板。
- **7.3 创建自己的简单模板**
  教读者把自己的成功经验写成可复用的模板。

### 第 8 章 Skill：给 Agent 增加一项能力

- **8.1 什么是 Skill**
  从模板的"固定提示"进阶到 Skill 的"扩展能力"，解释两者的区别。
- **8.2 Skill 的真实案例：从失败到成功**
  对应读者 D 的反馈，展示一个 Skill 设计的第一次失败原因、调整过程和最终效果，不只给最终结果。
- **8.3 在哪里找到和安装 Skill**
  介绍各产品的 Skill 市场和社区资源。

## 第五部分：理解 Harness

### 第 9 章 Harness：Agent 的安全网

- **9.1 Harness 解决了什么问题**
  通过一次任务失败和恢复的过程说明 Harness 的价值，不只画架构图。
- **9.2 Harness 如何工作**
  用通俗语言解释 Harness 的生命周期控制、错误恢复和过程管理机制。
- **9.3 新手需要关心 Harness 吗**
  说明哪些场景下 Harness 对新手有帮助，哪些场景可以暂时忽略。
