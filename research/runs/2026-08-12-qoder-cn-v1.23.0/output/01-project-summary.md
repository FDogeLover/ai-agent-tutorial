# 项目总结

## 1. 项目目标

制作一套面向**零基础或计算机基础较弱读者**的 AI Agent 桌面版教程，帮助读者：

1. 认识 AI Agent 是什么、能做什么；
2. 从七款桌面产品中选择适合自己的工具；
3. 用 Agent 完成真实的工作、生活或项目任务；
4. 逐步理解模板、Skill 和 Harness 等进阶概念。

## 2. 目标读者

| 特征 | 描述 |
|---|---|
| 已有经验 | 用过聊天式 AI（如问答、对话），但没有使用过能操作文件和工具的 Agent |
| 使用目的 | 希望处理工作、生活、内容创作或项目事务 |
| 技术水平 | 不熟悉命令行，更适合从桌面图形界面（GUI）开始 |
| 当前状态 | 已经零散使用过 Agent，但尚未建立稳定工作流 |

读者反馈样本（`02-reader-feedback.md`）进一步描绘了五类典型读者：

- **读者 A（普通办公用户）**：关心免费版能用多久，不理解 Credits / Token / API Key 的区别，产品太多不知从何开始。
- **读者 B（无编程基础）**：看到终端、Git、模型供应商就紧张，需要知道哪些按钮安全、哪些操作有不可逆风险。
- **读者 C（准备学编程）**：关心代码修改后如何确认没有改坏，仅展示生成代码不够。
- **读者 D（多 Agent 用户）**：需要 Skill 和 Harness 的真实案例，包括失败与恢复过程。
- **读者 E（重视稳定性）**：关注地区登录稳定性和付费后账号安全，需要申诉和替代方案。

## 3. 内容边界

### 3.1 产品范围

教程覆盖 **七款桌面 Agent**，按四类分组（参见 `images/interface-map.svg`）：

| 分组 | 产品 | 来源 |
|---|---|---|
| 海外闭源托管型综合 Agent | Claude 桌面版、Codex 桌面版 | `00-project-brief.md`、`03-product-facts.csv` |
| 国内综合型 Agent | TraeWork 中国版、WorkBuddy 桌面版 | 同上 |
| 代码优先型 Agent | Qoder 中国版、ZCode 中国版 | 同上 |
| 开源自主型 Agent | Hermes Desktop | 同上 |

### 3.2 明确排除

- **不以 CLI 或 TUI 为新手主入口**——教程从桌面 GUI 开始。
- **Qoder、TraeWork、ZCode 只采用中国版**的资料、账号和客户端，不混入国际版或旧产品线（如 QoderWork CN 的旧学生活动）。
- **不做脱离场景的总排名**——按使用场景和读者需求推荐，而非绝对排名。
- **不把单个账号封禁案例推导为普遍封号率**。

### 3.3 内容原则（来自 `00-project-brief.md`）

1. 先说适合谁和解决什么问题，再讲功能；
2. 区分**官方事实**、**实际测试**、**作者经历**和**待验证判断**；
3. 所有易变信息（价格、Credits、活动、账号可用性）标注日期、地区和产品线；
4. 删除、支付、发送、发布和扩大权限需要**人工决定**，不自行执行。
