# AI Agent 新手上路

一套写给零基础用户的 AI Agent 实践教程：帮助读者理解 Agent、选择合适的工具，并逐步建立自己的工作流、Skills 与 Harness 工程体系。

教程统一以具有图形化界面的桌面版本为准，通过窗口、菜单、按钮和可视化任务过程进行讲解，不把 CLI 或 TUI 命令行版本作为主教程对象。

## 这套教程解决什么问题

市面上的 AI Agent 很多，但新手真正困难的通常不是“不会点按钮”，而是：

- 不知道 AI Agent 与普通 AI 对话工具有什么区别；
- 不知道自己的需求适合哪一类 Agent；
- 不知道怎样描述任务、提供上下文和检查结果；
- 试用几个产品后，仍然没有形成稳定、可复用的工作方式；
- 想进一步使用 Skills、规则、记忆和多 Agent，却缺少清晰的工程框架。

本教程将以真实任务为主线，结合 Codex、Claude、Z Code、TreeWork、Work Buddy、Qoder 和 Hermes 的使用经验，从“第一次使用”逐步走向“搭建自己的 Agent 工作系统”。

## 目标读者

- 没有编程基础，但希望用 Agent 处理工作和生活事务的人；
- 使用过聊天式 AI，准备尝试能读写文件、调用工具和执行任务的 Agent 用户；
- 已经零散使用 Agent，希望建立稳定工作流的人；
- 想理解 Skills、项目规则、上下文管理与 Harness 架构的进阶用户。

## 学完之后，你将能够

1. 判断一个任务是否适合交给 Agent；
2. 按任务类型、权限、交互方式和成本选择工具；
3. 用“目标—上下文—约束—验收”方式清楚地布置任务；
4. 管理文件、权限、风险、任务进度和结果验证；
5. 把重复经验沉淀为模板、规则和 Skills；
6. 搭建包含 Agent、工具、上下文、记忆、验证和反馈的 Harness；
7. 根据自己的工作与生活场景建立个人 Agent 系统。

## 推荐阅读路线

- 完全新手：按正式篇章顺序阅读，并完成每章练习；
- 办公与生活用户：重点阅读基础篇、选型篇、上手篇和案例篇；
- 开发与项目用户：快速读完基础篇，重点阅读协作篇和工程篇；
- 已有经验的用户：直接从 Skills、Harness 与个人系统搭建开始。
