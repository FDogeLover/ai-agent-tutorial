# AI Agent 教程共同基准材料包 v1

## 用法

1. 为待测产品复制一份 `input` 目录；
2. 新建空的 `output` 目录；
3. 将 `input/OUTPUT-REQUIREMENTS.md` 中的统一任务原样交给 Agent；
4. 不添加产品专属初始化文件，不提前整理材料；
5. 使用 `acceptance-checklist.md` 验收并记录人工介入。

完整原则见 `docs/08-common-benchmark-task.md`。

## 当前版本

- 版本：v1；
- 创建日期：2026-08-12；
- 文件类型：Markdown、CSV、SVG；
- 事实范围：教程框架与本机桌面客户端核对；
- 联网要求：第一轮禁止联网补充事实。

## 冻结规则

开始第一款产品测试后，不修改 v1 输入材料。需要修订时复制为 v2，并在新目录记录变更原因。七款产品必须使用同一个材料包版本。
