# 零散教程笔记

以下内容来自框架讨论，尚未按正式章节整理：

- 新手最先遇到的问题不是提示词，而是不知道该选什么软件、文件放在哪里、Agent 做到哪一步。
- 产品介绍需要有真实截图，但截图不能只是装饰，要解释入口、操作、结果或风险。
- Claude 和 Codex 都有较强综合能力；作者的 Claude 账号已被封，具体原因还没有核实。
- TraeWork 登录后有 Work、Code、Design 三个模式，应该分别观察。
- WorkBuddy 登录后的首页有办公、代码、设计场景，还有助理、项目、技能、自动化和资料库。
- Qoder CN 以 Quest 为主要任务单位；不要混入 QoderWork CN 的旧学生活动。
- ZCode 有分组、项目、自动化、技能、权限和模型选择，对新手可能既自由又复杂。
- Hermes Desktop 有成熟 GUI，但模型、环境和维护仍然需要计算机基础。
- 先完成一个小任务，再讲模板、Skill、Harness 和多 Agent。
- Harness 不能只画架构图，要通过一次失败和恢复说明它解决了什么问题。
- 部署网站和视觉设计暂时不决定，但页面文件名、更新时间、图片替代文字应提前统一。
- 价格、Credits、活动和账号可用性都容易变化，应该集中维护。

仍需作者决定：

- 第一批正式发布哪些章节；
- 第一篇完整案例选择工作、生活、内容还是代码项目；
- 网站使用哪种技术部署；
- 是否邀请零基础读者参与测试，以及如何收集反馈。
