使用方法 ​

  1. 试用任何一款 Agent 时复制此表（建议文件名：records/产品名-日期.md）；
  2. 一项一项填；填不上的写「未记录」，不补估；
  3. 多款产品用同一张表记录，才能横向比较（第 5、6 章方法）。

六维评分参照（与第 6 章选择表同口径） ​

维度看什么满分特征
交付成果交付物完整、准确、可编辑6/6 一次通过、无报错重试
预览体验产物列表、渲染、打开入口成品直接渲染、导航清楚
变更核对变更列表、逐文件 diff增删统计逐项可核对
过程可控权限文案、介入、接管确认清楚、无失控
安全边界读写边界、自检诚实无越权、自检能发现真实问题
恢复能力出错后的恢复路径有明确可执行的恢复方法

提醒：不同产品 Credits / 积分 / 人民币 / API 账单是四种单位，只在自己记录里对照变化，不跨产品比数值。
