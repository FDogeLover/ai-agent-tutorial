# Hermes Desktop 体验

> 本机版本：桌面应用 0.17.0（Electron 版本 40.10.2 不是产品版本）；实测 2026-08-12；订阅核验 2026-08-11
>
> 测试条件：OpenCode Go + DeepSeek V4 Flash + 最高推理 + 智能审批。约 5–7 分钟是上述组合共同作用的结果；成本未知，不估算（「DeepSeek API 通常较便宜」不是本轮成本证据）。

## 1. 一句话结论

**高自主、模型自由、自托管型 Agent 的代表**：预览/源码/差异/编辑四视图最灵活，也是本轮唯一触发并**自动恢复真实路径错误**的样本（误写 → 自动迁移 → 删除误建目录 → 哈希复核，全程无需人工）。「极客属性」来自模型接入、配置自由度与维护责任，而非界面简陋——GUI 本身成熟易用。适合有系统配置经验的读者，不适合零基础。

## 2. 关键事实

- **产品与版本**：Hermes Desktop（Nous Research 的 Hermes Agent），0.17.0；注意与同名模型、纯 CLI 版本区分；Windows 10/11（官方支持 macOS 12+）
- **账号与计费**：无强制账号（应用 MIT 开源免费）；模型账单来自所连接供应商；首次使用需配置 Provider（API Key/Endpoint）——新手主要门槛
- **入门分组**：开源自主型 Agent；建议基础：编程或系统配置经验
- **运行方式**：自托管（本地应用 + 外部模型供应商）；自主程度：高
- **官方更新日志**：GitHub Releases（NousResearch/hermes-agent）；本机 0.17.0（06-19）早于官方最新 v0.20.0（08-03：实时语音、A2A 跨代理通信、桌面端平台化）——**本页结论基于 0.17.0，新版本能力未实测**

## 4. 核心能力

- **已验证**：6 份 Markdown 最终完成；四视图切换（预览/源码/差异/编辑）、自动恢复、多供应商接入；自检诚实披露路径偏差（透明度较高）
- **入口可见未实测**：消息平台集成、技能与工具、Profiles、自动化与长期项目
- **新手路径**：新建 Project → 选运行目录 → 配置 Provider 与模型 → 粘贴提示词 → 发送（需先跨过 Provider 配置）

## 5. 实测记录（共同基准任务）

- **结果**：6/6 最终完成，7/7 输入 SHA-256 与基线一致；总用时约 5–7 分钟；人工 0 / 权限确认 0（智能审批未触发）
- **自动恢复（七款中唯一实证）**：执行时当前目录位于 `input`，前两份文件被相对路径误写入 `input/output/`，随后 Agent 自行迁移到根 `output/`、删除误建目录并复核输入哈希——全程无需人工
- **问题**：① **越权读取**——可读取整个 Project，自检引用根目录运行文件（智能审批未弹窗 ≠ 严格限制读取）；② 把「误写后清理」仍评为权限边界全部遵守，结论过宽；③ 自行压缩为第 0–7 章目录（只能作基准答卷）
- **教学价值**：误写恢复案例是「最终正确 ≠ 过程合规」的绝佳素材——安全、恢复、透明度应分开评价
- **边界**：Provider 不可用、上下文过长、权限拒绝等恢复场景待 benchmark v2 补测

## 7. 适合与不适合

**适合**：重视模型自由、多供应商接入的自托管用户；需要高自主、长期自动化任务的用户；愿意承担环境配置与维护责任的读者。

**不适合**：零基础新手（Provider/模型/环境概念门槛高）；不想管理 API Key 与外部账单的用户（成本不可见）；对数据边界有严格要求且不希望「无弹窗越权读取」的用户（本轮存在边界失分）。

## 8. 最终结论

- **不优先推荐新手试用**：先通过第 2 章理解模型/API 概念，熟悉环境后再试
- **定位**：**自托管型主 Agent 候选**；高自主任务与自动化场景价值最大；应用开源免费，模型按需付费
- **与相邻产品差异**：与 ZCode 同属 BYOK 路径——Hermes 恢复能力唯一实证（自动恢复），ZCode 变更统计更细；与托管路径（Codex/WorkBuddy 等）相比配置自由度最高、开箱即用性最低
- **待核验**：Provider 不可用时的恢复、消息平台集成、长期自动化稳定性、精确成本核算、v0.20 新能力
