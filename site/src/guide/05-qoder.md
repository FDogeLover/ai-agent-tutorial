# Qoder 中国版体验

> 本机版本：应用 1.23.0（壳 1.106.3）；实测 2026-08-12；订阅核验 2026-08-11
>
> 测试条件：Auto 配置（底层模型未显示），结论只对应本账号、本版本与默认权限。

## 1. 一句话结论

本轮实测**最快最省**的产品：2 分钟完成 6/6 交付、6.32 Credits / ¥0.25，任务卡直接展示人民币费用，审查视图支持暂存/丢弃/提交。但存在**关键安全边界问题**：在无权限弹窗的情况下读取了 input 之外的工作区文件，且自检未发现——「0 弹窗」不等于「合规」，效率与边界必须分开评价。

## 2. 关键事实

- **产品与版本**：Qoder 中国版（`QoderCN`），1.23.0；同目录另有国际版 `Qoder` 与 `QoderWork CN`，三者不能共享价格/福利/截图结论
- **地区与计费**：中国区账号，人民币计价（Credits）；**必须使用中国站价格**，不用国际站 $20/$60/$200
- **入门分组**：代码优先型 Agent（国内）；建议基础：一般数字工具经验（代码用户友好）
- **运行方式**：云端（Credits 计费）；自主程度：中—高
- **官方更新日志**：docs.qoder.cn；本机 1.23.0（08-06：实时语音协作、定时任务升级、HTTP Hooks）；官方最新 v1.24.1（08-12：对话级代码评审、**危险命令识别增强**——未声明修复越界读取）

## 4. 核心能力

- **已验证**：6 份 Markdown 一次生成；交付报告表（文件/路径/大小）、预览/代码双视图、审查视图（暂存/丢弃/提交）；操作统计（已处理 25 个操作）
- **入口可见未实测**：定时任务、Better Harness、知识中心、插件市场
- **新手路径**：打开 QoderCN → 新建 Quest → 选工作空间 → 粘贴提示词 → 发送

## 5. 实测记录（共同基准任务）

- **结果**：6/6 交付一次生成，7/7 输入 SHA-256 与基线一致；总用时 2 分钟（08:13–08:15:21）
- **介入**：人工 0 / 权限确认 0（但**无弹窗 ≠ 只读指定目录**）
- **亮点**：信息缺口分类清楚（新增项标注推断/建议）；结构可继续编辑
- **问题（关键）**：① **越权读取**——读取了 input 之外的运行文件，把测试前状态写入成品（如「共同任务尚未执行」的过时结论）；② **自检不可信**——待办保持未勾选、自检却称 25 项全部通过；③ 自行生成七部分 12 章目录（只能作基准答卷）
- **边界**：优势任务（代码项目修改/审查）待 benchmark v2 统一测试

## 7. 适合与不适合

**适合**：追求速度与成本透明、以代码/Quest 任务为主的用户（2:00 / ¥0.25 人民币直显）；需要审查提交能力的代码用户；中国区用户。

**不适合**：对数据边界敏感的读者（本轮存在无弹窗越权读取）；完全依赖 Agent 自检判断交付质量的用户（自检失真需人工核验）；零基础新手（Quest 与 IDE 工作区需要适应）。

## 8. 最终结论

- **有条件推荐**：体验版免费可试；首次使用就应检查产物是否引用了工作区其他文件
- **定位**：**代码/任务型主 Agent 候选**（托管路径中效率最高）；代码任务为主、速度成本敏感时专业版 ¥59/月起步性价比高
- **与 ZCode 差异**：同属代码优先型——Qoder 托管 Auto 路径（快、便宜、边界失分），ZCode BYOK 路径（变更透明最强、需配置模型）；两者代码优势任务均待 v2 统一测试
- **待核验**：越界读取是否修复（官方 1.24.1 增强危险命令识别但未声明）、自检质量、代码优势任务、变更 diff 完整性
