# TraeWork 中国版体验

> 状态：正文完成；共同基准任务已实测（2026-08-12）

## 1. 一句话结论

「国内综合型」里**对零基础门槛最低**的选项之一：0 人工介入、无需配置模型、Work/Code/Design 三模式让新手按任务类型选入口。实测 5 分 51 秒完成 6/6 交付、消耗 37.71 积分。短板：本轮未留存审阅/差异截图（变更能力范围未验证）、具体模型名称未记录。

## 7. 三类实测任务

### 7.1 共同基准任务（2026-08-12）

#### 任务背景

使用冻结的教程材料包（`input/` 7 份文件），整理 AI Agent 教程材料，生成六个指定交付文件并自检。

#### 完整输入

冻结材料包 + `traework-prompt.md` 统一提示。

#### 执行过程

打开 TraeWork → 选择 Work 综合任务模式 → 选择运行目录 → 保持默认模型与权限 → 粘贴统一提示发送。

#### 最终结果

六份指定文件按顺序生成（07:56:07 首文件至 07:59:35 末文件），总用时 5 分 51 秒（测试者记录；首末文件间隔 3 分 28 秒）。

#### 验收情况

- 交付：6/6 一次通过，无权限确认、人工回复、中断、报错或重试；7/7 输入 SHA-256 与基线一致；
- 内容亮点：信息缺口分类清楚（D6–D9 标注为整理者推断）；待办可勾选；自检覆盖交付、权限、质量与未解决问题；
- 内容偏差：自行生成五部分、15 章目录，只能作为基准答卷不能替换正式 23 章框架；把部分 SVG/CSV 输入推导为「协议已完成」的表述强于材料可支持的程度；
- 指标：澄清 0 / 权限确认 0 / 人工回复 0 / 中断 0 / 报错 0 / 重试 0。

## 9. 适合与不适合

### 更适合

- 零基础、中文办公为主的新手（三模式入口降低选择成本）；
- 希望用免费额度先体验的用户（Free 500 积分/月，本轮单任务 37.71 积分）；
- 办公、文档整理、任务型工作为主的场景。

### 可能不适合

- 需要审阅/差异核对能力的用户（本轮该环节未验证，需自行确认）；
- 需要 BYOK/自定义模型自由度的用户（官方文档暂无该能力说明）；
- 对「Agent 改了什么」有强核对需求的用户——建议与 WorkBuddy、ZCode 的变更视图对比后再定。

## 10. 最终结论

- 是否推荐新手试用：**推荐**，作为国内综合型首选试用之一；
- 什么条件下值得购买官方订阅：免费额度耗尽且日常任务量稳定时，Lite/Pro 起步；新人首月价可降低试错成本；
- 最适合作为主 Agent、辅助 Agent 还是专用工具：**国内办公场景主 Agent 候选**；
- 与相邻产品的差异：与 WorkBuddy 同为国内综合型，0 介入与无需配置一致；TraeWork 三模式更直观，WorkBuddy 变更可见性更好（+647/-0 diff）；两者成本单位不同（积分 vs Credits）不可横比；
- 仍需要后续版本继续核验：变更/审阅环节能力、实际模型名称、新人福利到账条件、Code/Design 模式实测。
