# WorkBuddy 体验

> 本机版本：5.3.11 / 5.3.12（界面截图）；实测 2026-08-12；订阅核验 2026-08-11

## 1. 一句话结论

**零基础/中文办公最省心的选择之一**：0 人工介入、无需配置模型，成品直接 Markdown 渲染，变更统计与逐文件 diff 一目了然（本轮 +647/-0）。实测 5 分 45 秒完成 6/6 交付、消耗 67.25 Credits（本轮托管路径最高）。注意一处不一致：产物列表 6 份 vs 变更列表只显示 5 份，核对时两处都要看。

## 2. 关键事实

- **产品与版本**：Tencent WorkBuddy 桌面工作台（腾讯出品），5.3.11/5.3.12，Windows
- **地区与计费**：个人版美元计价（workbuddy.ai）；腾讯云中国区另有人民币产品页，两处价格分开核对；本页以国际个人版为主
- **账号**：需要账号登录；测试时正常；本轮 0 权限弹窗
- **入门分组**：国内综合型 Agent；建议基础：零基础
- **运行方式**：云端（Credits 计费）；自主程度：中
- **官方更新日志**：codebuddy.cn/docs/workbuddy/Changelog；5.3.12（08-12）与截图一致（灵感分享口令、同步稳定性、样式优化）；5.3.11（08-07）新增「检查网络」、企业微信/微信流式输出、任务批量删除

## 4. 核心能力

- **已验证**：6 份 Markdown 成品一次生成；任务总结报告、产物卡片、Markdown 直接渲染、变更列表 + 逐文件 diff、`@`/`/` 指令；只读取 input 材料包，未发现越界读取
- **入口可见未实测**：自动化、资料库、专家/技能/连接器、视频生成等扩展
- **新手路径**：日常办公 → 选工作空间 → 粘贴提示词 → 发送（无需配置模型）

## 5. 实测记录（共同基准任务）

- **结果**：6/6 交付一次通过，7/7 输入 SHA-256 与基线一致；总用时 5 分 45 秒（07:23:45–07:26:43）
- **介入**：人工 0 / 权限确认 0 / 澄清 0 / 恢复 0
- **亮点**：结构化整理、信息缺口识别、新手化目录组织较好；没有编造 Claude 封号原因
- **偏差**：① 自行生成 21 章目录，把输入包未提供的正式目录当待办——只能作为基准答卷，不能覆盖正式框架；② 「查看所有变更」只显示 5 份，漏 `06-self-check.md`，与 6 份产物不一致（新手可能只信其中一个视图，两处都要看）
- **边界**：优势/边界任务候选（自动化、Credits 耗尽恢复）待 benchmark v2 统一测试

## 7. 适合与不适合

**适合**：零基础中文办公新手（0 介入、免配置）；希望「成品和改了什么看得见」的用户；需要自动化/资料库扩展的办公场景。

**不适合**：Credits 敏感用户（67.25 为本轮托管路径最高，按自身任务量评估）；强代码/Git 工作流用户（代码能力本轮未验证，对照 Qoder/ZCode/Codex）；要求交付清单与变更视图完全一致的严格核对者（6 vs 5 需人工注意）。

## 8. 最终结论

- **推荐新手试用**：国内综合型首选之一。Free 额度（100 + 250 + 每日活跃）用完后、日常任务量稳定再考虑 Pro；先观察自己单任务的 Credits 消耗
- **定位**：国内办公场景**主 Agent 候选**；自动化与资料库适合作长期辅助
- **与 TraeWork 差异**：同为国内综合型 0 介入，但 WorkBuddy 变更可见性（+647/-0 diff）有截图实证，TraeWork 变更环节未验证；成本口径（Credits vs 积分）不可横比
- **待核验**：变更列表遗漏的产品修复、自动化/资料库实测、5.3.11→5.3.12 差异、中国区购买路径
