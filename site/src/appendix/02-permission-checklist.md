# 附录 C：权限分级与安全检查清单

## 权限分级速查（对应第 8 章）

| 级别 | 允许什么 | 典型操作 | 新手建议 |
|---|---|---|---|
| **L0 只读** | 读取、分析、总结 | 读文件、查资料、出建议 | 从这级开始 |
| **L1 写入（限定目录）** | 在指定目录建/改文件 | 输出文档、整理素材 | 输出到独立 `output/` |
| **L2 执行** | 运行命令/脚本 | 批量操作、跑脚本 | 默认关闭，白名单制 |
| **L3 外部操作** | 联网、发送、发布、付款 | 发邮件、下单、删远程 | 永远人工确认 |

## 任务前安全检查

- [ ] 已建独立目录：`任务名/input/`、`output/`、`backup/`；
- [ ] 关键文件已备份（原文件复制到 `backup/`）；
- [ ] 权限卡已写（读取/写入/执行/外部四行允许与禁止）；
- [ ] 已记录输入基线（如 SHA-256 哈希，用于事后比对）；
- [ ] 任务卡约束里写明了读取范围、写入位置、联网策略；
- [ ] 任务卡里没有粘贴密码、Token、身份证号等敏感信息。

## 任务中检查（按监督档位）

- [ ] Agent 是否只读允许范围？（看它的动作/日志，不只看弹窗）
- [ ] 是否出现未授权的联网/执行/写入？
- [ ] 是否反复重试同一失败操作（>2 次应插话）？
- [ ] 分段确认点是否到了？到了就停下来验收。
- [ ] 权限弹窗出现：看不懂就先拒绝，查清楚再授权。

## 任务后检查（边界验收）

- [ ] 产物数量、名称、位置与任务卡交付物一致；
- [ ] 输入文件哈希与基线一致（7/7、8/8 等）；
- [ ] 读取/写入记录中没有越界项（有则记录并评估影响）；
- [ ] `output/` 之外的目录没有被创建或修改；
- [ ] 产物中没有泄漏账号、路径、密钥信息；
- [ ] 所有「未核实」信息已标注，没有被写成事实。

## 高风险动作红线（永远人工确认，不做成自动步骤）

| 动作 | 处理 |
|---|---|
| 删除、覆盖、格式化 | 先备份；人工确认后才执行 |
| 发送、发布、对外提交 | 内容验收合格 ≠ 可以发布；发布动作人来做 |
| 付款、购买 | 永远人工执行最后一步 |
| 提供敏感信息 | 不写入任务卡；用变量/外部配置 |
| 运行不认识的脚本 | 先审内容，再决定是否运行 |

## 反直觉提醒（实测教训）

- **没有权限弹窗 ≠ 没有越权行为**（第 5 章 Qoder/Hermes 实测）；
- **自检通过 ≠ 结果合格**（第 5 章 Qoder 自检漏报实测）——边界验收必须独立于 Agent 的自检；
- **最终状态正确 ≠ 过程合规**（第 5 章 Hermes 误写后自动恢复实测）——过程记录与结果分开评价。
