## 本附录解决什么问题

第 5 章产品页讲了每款产品的下载来源，第 23 章 D3 让你「安装/登录产品」——但如果你**从来没在电脑上装过软件**，第一步就可能卡住：下载按钮在哪？装了会不会搞坏电脑？为什么弹窗警告我？本附录把这些「没人教过你」的部分补齐。

## 0. 装之前，先确认三件事

1. **电脑系统**：本教程七款产品都需要 Windows（10 或 11）或 macOS（12 以上）。手机和平板装不了桌面 Agent——手机上的 AI 应用与桌面 Agent 不是一回事，本教程不讲手机端。**没有电脑或不想用电脑，可以只读前半本书**（认知、选择、工作流概念），动手练习留到有电脑时再做。
2. **网络**：下载和登录都需要网络。下载慢可以换时间或换网络再试，不用急。
3. **账号**：多数产品需要注册账号（手机号或邮箱）。注册时留意：登录后一般都有免费额度，先别急着付费（新人福利看清期限，第 4 章讲过）。

## 1. 下载：认准官网，避开「下载站」

- 打开产品**官网**，找页面上的「下载」按钮（一般在首页顶部或右上角）。七款产品的官方下载来源见第 5 章各产品页的「官方下载来源」行。
- ⚠️ 搜索时**不要点**标着「高速下载」「破解版」「某某软件园」的结果——那些是第三方下载站，可能捆绑垃圾软件。认准官网域名。
- 下载完成后，文件通常在你的「下载」文件夹（浏览器默认位置），文件名以 `.exe`（Windows）或 `.dmg`（macOS）结尾。

## 2. 安装：双击它，一路「下一步」

**Windows**：

1. 打开「下载」文件夹，**双击**刚下载的 `.exe` 文件；
2. 如果弹出蓝色/黄色提示「Windows 已保护你的电脑」——点 **「更多信息」→「仍要运行」**（这是 Windows 对新软件的常规提示，官方安装包都会遇到，不用慌）；
3. 安装向导出现后，一直点 **「下一步 / Next」**，目录用默认的就行（不用改）；
4. 点 **「安装 / Install」**，等进度条走完，点 **「完成 / Finish」**。

**macOS**：

1. 双击 `.dmg` 文件，会弹出一个窗口；
2. 把窗口里的 App 图标**拖到「应用程序」文件夹**上（系统提示就拖这个）；
3. 第一次打开时若提示「无法打开，因为来自身份不明的开发者」——去 **「系统设置 → 隐私与安全性」**，点「仍要打开」。

装完的软件会在**桌面**或**开始菜单**（Windows）/ **启动台**（macOS）出现图标。

## 3. 登录/注册：用手机号或邮箱

- 打开软件 → 点「登录/注册」→ 选手机号或邮箱 → 收验证码 → 完成。
- 登录后先看看：有没有**免费额度**、试用期多久、界面提示了什么新手引导。**先不要急着付费**（第 4 章讲过怎么判断值不值）。
- 如果登录失败：检查网络、检查验证码是否过期、换个浏览器/重开软件再试。

## 4. 首次使用：从「只读」开始

- 登录后先点「新建任务/新建对话」，随便发一句话试试（如「你好，介绍一下你能做什么」），确认它能回复；
- 第一次跑真实任务前，**给 Agent 的权限先给最小**（第 8 章的 L0 只读），让它先读材料出计划，你看完再升级权限；
- 如果它弹出「允许访问文件夹/执行命令」之类的授权请求——**先看它要什么**，只读任务不需要它运行命令。

## 5. 常见问题速查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击安装包没反应 | 下载不完整 / 被杀毒软件拦截 | 重新下载一次；检查杀毒软件隔离区，把该文件恢复并「允许」 |
| 提示「Windows 已保护你的电脑」 | Windows 对新软件的常规提示 | 点「更多信息 → 仍要运行」（官方安装包可放心） |
| 下载特别慢 | 网络/服务器波动 | 换网络或换个时间段重试；不要在浏览器里开很多下载任务 |
| 安装到一半报错 | 磁盘空间不足 / 权限问题 | 清理磁盘空间；右键安装包「以管理员身份运行」 |
| 打开软件是英文/界面空白 | 首次加载慢 / 需要更新 | 等 1-2 分钟；重启软件；检查软件内「更新」 |
| 登录收不到验证码 | 网络/短信通道延迟 | 等 1 分钟重发；检查手机号是否输错 |
| 找不到桌面图标 | 安装到了开始菜单 | Windows 按开始键搜索软件名；macOS 在启动台找 |
| 软件能打开但发任务没反应 | 网络 / 账号未激活 | 检查网络；退出重登；看软件内「检查更新」 |

## 7. 安装不上时，还有一条路

如果装软件这一步实在过不去（电脑太老、不敢操作、被限制安装）：**先把第 1-4 章读完**（认知与选择不需要装任何软件），练习用纸笔完成（序章说过，任务种子用纸笔记录完全可行）；等有条件时再回来装。教程的方法论不依赖任何具体软件。
