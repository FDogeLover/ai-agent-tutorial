# 第 21 章：内容创作与研究案例——从「一堆经验」到「一套教程」

> 页面标识：ch-21-content-research-case
>
> 摘要：用本书项目的真实过程演示内容策划与研究类任务：选题、素材盘点、框架设计、可信度管理、长文协作。
>
> 适合人群：所有人—中级｜难度：中级｜阅读时间：约 30 分钟
>
> 创建日期：2026-08-13｜最后核验：2026-08-13｜标签：案例、内容、研究、第四篇实战

## 案例摘要

- 使用场景：内容创作与研究
- 使用者基础：能完成第 1–14 章学习即可复现
- 使用的 Agent：桌面 Agent + 视觉模型辅助（第 5 章界面讲解文档的素材流程）
- 完成时间：跨周迭代（本书项目本身）
- 风险等级：低—中（事实可信度管理是重点）
- 最终交付物：23 章教程框架 + 各章正文（含你正在读的这一章）

## 任务背景

作者有多款 AI 产品真实经验，想写零基础读者教程。难点：经验散落十几个文档、截图、聊天记录，不成体系；市面资料多是产品说明书或「参数党」评测，缺「教人怎么用」的实践教程。

## 原始需求

> 「我想写一套 AI Agent 教程，把我用这些产品的经验整理出来，教普通人怎么选、怎么用。」

（模糊版：未定读者、范围、结构——直接让 Agent 写会得到一篇四不像。）

## 任务判断

- 适合 Agent：素材整理、框架梳理、长文起草、格式统一；
- 交给 Agent：素材盘点、目录草案、各章起草、术语统一、易变信息核验；
- 人必须做：定读者与边界（零基础、只讲桌面版）、定框架（23 章六篇）、事实分级、下写作结论。

## 整理后的任务卡（框架设计阶段）

- **目标**：产出教程的完整目录框架与写作规范；
- **上下文**：零基础读者；只讲桌面 GUI 版；Qoder/TraeWork/ZCode 只用中国版；
- **输入材料**：作者经验笔记（多份文档）；
- **范围与约束**：不把个案写成普遍规律（如 Claude 封号）；易变信息标注核验日期；不虚构引用；
- **交付物**：23 章目录（`docs/01-book-outline.md`）、编辑规范（`docs/03`）、内容清单（`docs/04`）；
- **验收标准**：目录覆盖「认识→选型→任务→工作流→Harness→案例」六篇；每章有明确产出；规范含术语与事实分级要求。

## 执行过程

1. **盘点**：经验文档集中到项目目录，用 Agent 提取「可用素材」；
2. **定框架**：人先定六篇叙事线（第 5 篇内容策略），Agent 扩展为 23 章；
3. **定规范**：写作纪律写入 `docs/03`（先结论、术语白话、事实分级）；
4. **逐章起草**：用模板（`templates/chapter-template.md`）逐章生成；
5. **易变信息集中管理**：价格/福利统一放 `docs/07`，各章引用而非复制。

## 出现的问题

- **幻觉风险**：起草时「编造价格」「虚构来源」——第 10 章事实核查拦截；
- **范围漂移**：初版混入「命令行」「模型原理」，违反「零基础、GUI」边界——人修正；
- **事实分级混淆**：作者封号经历差点写成「该产品容易封号」——改为个案；
- **版本过期**：QoderWork 学生福利已截止仍当新福利——`docs/07` 核验拦截。

## 修正与判断

- 建立「三色事实标注」：官方事实 / 实测结果 / 作者推断，写入 `docs/03`，各章按附录 C 自查；
- 目录砍掉 CLI 与模型原理，移入「选读附录」；
- 价格统一标注核验日期，活动截止的只作历史信息；
- 统一章节模板保证 20+ 章结构一致（第 12 章模板库的价值）。

## 最终结果与验收

- 产出：23 章框架 + 编辑规范 + 内容清单 + 第 5、6 章完整正文 + 其余章节正文；
- 验收：每章过「模板结构」「术语白话」「事实分级」三项检查；链接批量校验（第 18 章回归验证的实践）；
- 持续迭代：内容清单（`docs/04`）打勾管进度，易变信息定期复核。

## 复盘

- Agent 做得好：结构扩展、逐章起草、格式统一、批量校验；
- 人必须介入：边界与口径、事实分级、最终结论；
- 可沉淀：章节模板（`templates/chapter-template.md`）、编辑规范（`docs/03`）、易变信息表（`docs/07`）——**内容创作类任务的完整方法论**。

## 给新手的最小版本

30 分钟复现：选一个熟悉话题（如「如何挑选跑步鞋」）→ 写三条纪律（如「价格标日期」「不写没验证的数据」）→ 用任务卡让 Agent 起草一篇带模板结构的短文 → 按纪律验收。**内容创作的核心不是「让 AI 写」，而是「定边界、给模板、管事实」。**
