# 章节草稿

本目录用于存放正式章节。建议使用两位数字编号，例如：

- `00-preface.md`
- `01-what-is-an-agent.md`
- `02-capabilities-and-limits.md`
- `04-how-to-choose.md`
- `07-task-brief.md`

每章从 `templates/chapter-template.md` 复制开始。尚未开始写作的章节不必提前创建空文件。
