# TraeWork 中国版体验

> 本机版本：0.1.47（构建 2.3.68299）；实测 2026-08-12；订阅核验 2026-08-11

## 1. 一句话结论

「国内综合型」里**对零基础门槛最低**的选项之一：0 人工介入、无需配置模型、Work/Code/Design 三模式让新手按任务类型选入口。实测 5 分 51 秒完成 6/6 交付、消耗 37.71 积分。短板：本轮未留存审阅/差异截图（变更能力范围未验证）、具体模型名称未记录。

## 4. 核心能力

- **已验证**：6 份结构化 Markdown 一次生成；三模式入口、任务摘要与产物清单、Markdown 成品渲染；只读取 input 材料包，未发现越界读取
- **入口可见未实测**：Code/Design 模式完整能力、插件市场、自动化、办公助理、模板库
- **新手路径**：新建任务 → Work 模式 → 选工作目录 → 粘贴提示词 → 发送
- **如实说明**：变更/差异/审阅环节本轮未留存截图，**能力范围标注为「未验证」**；界面未见与 WorkBuddy 类似的「文件变更 + diff」面板入口

## 5. 实测记录（共同基准任务）

- **结果**：6/6 交付一次通过，7/7 输入 SHA-256 与基线一致；总用时 5 分 51 秒
- **介入**：人工 0 / 权限确认 0 / 中断 0 / 报错 0 / 重试 0
- **亮点**：信息缺口分类清楚（D6–D9 标注为整理者推断）；待办可勾选；自检覆盖交付、权限、质量与未解决问题
- **偏差**：自行生成五部分 15 章目录（只能作基准答卷，不能替换正式 23 章框架）；把部分 SVG/CSV 输入推导为「协议已完成」的表述强于材料可支持的程度
- **边界**：优势任务（代码/设计模式）、边界任务待 benchmark v2 统一测试

## 7. 适合与不适合

**适合**：零基础中文用户（三模式按任务类型选入口、0 介入）；Office/设计/代码多场景都要用的用户。

**不适合**：需要审阅/差异确认的严格核对者（本轮变更能力未验证）；需要 BYOK/自定义模型的用户（无公开说明）。

## 8. 最终结论

- **推荐新手试用**：国内综合型首选之一；Free 500 积分起步，先观察单任务积分消耗
- **定位**：**零基础办公主 Agent 候选**；三模式适合任务类型混合的用户
- **与 WorkBuddy 差异**：同为国内综合型 0 介入；TraeWork 三模式更直观，WorkBuddy 变更可见性（+647/-0 diff）有截图实证、TraeWork 变更环节未验证；成本口径（积分 vs Credits）不可横比
- **待核验**：新人 4,500 积分活动规则、变更/审阅能力、Code/Design 模式实测、模型名称
