# TraeWork 中国版体验

> 状态：骨架；待统一任务
>
> 本机版本：产品 0.1.47；可执行构建 2.3.68299
>
> 最后本机核对：2026-08-12

## 1. 一句话结论

面向中文工作、代码和设计场景的多模式桌面工作台；真正价值在于 `Work / Code / Design` 三种模式是否能形成稳定交付闭环。

## 2. 测试版本和地区

- 只测试中国版；
- 本机目录和可执行文件名为 `TRAE SOLO CN`；
- 窗口标题为 `TraeWork CN`；
- 不混用 Trae CN 的 IDE、价格或模型配置。

## 3. 下载、安装与首次启动

记录中国站下载、账号登录、三种模式入口、首次授权和工作目录选择。

## 4. 免费额度、订阅与计费

核对 Free、Lite、Pro、Pro+、Ultra 的 Credits、重置周期和新人活动。客户端弹窗与官方网页逐项对应。

## 5. 核心能力

按 Work、Code、Design 分别观察办公、文件、网页、代码、图片和设计产物，不用单一任务代表全部能力。

## 6. 界面与工作方式

左侧包含模式切换、新建任务、插件市场、设计系统、办公助理和任务列表；中间展示任务过程与产物卡片；底部是统一输入区。

## 7. 三类实测任务

### 7.1 共同基准任务

使用 Work 默认模式处理教程材料包，并生成统一 Markdown 交付物。

### 7.2 优势任务

候选：将教程资料制作成报告、表格和演示文稿，或在 Design 模式生成页面原型。

### 7.3 边界任务

测试跨模式切换、Credits 不足、产物无法打开或工作目录权限受限时的恢复。

## 8. 遇到的问题与恢复

重点记录模式差异、产物存放位置、更新弹窗、Credits 提示和重新进入任务的方法。

## 9. 适合与不适合

更适合中文综合工作和希望一个入口覆盖多种任务的新手。可能不适合需要高度自由模型配置或完全本地运行的用户。

## 10. 最终结论

待分别完成 Work、Code、Design 代表任务后形成，不按界面入口数量直接判断能力。
