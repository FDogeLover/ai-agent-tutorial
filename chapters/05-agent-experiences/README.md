## 四类入门分组

- 海外闭源托管型综合 Agent：Claude、Codex；
- 国内综合型 Agent：TraeWork 中国版、WorkBuddy；
- 代码优先型 Agent：Qoder 中国版、ZCode 中国版；
- 开源自主型 Agent：Hermes Desktop。

分组只用于帮助新手建立第一印象，不代表能力排名。七款产品必须使用相同结构、共同基准任务和验收口径，最终在第 6 章进行横向选择。
