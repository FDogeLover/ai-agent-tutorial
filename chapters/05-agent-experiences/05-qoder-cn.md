# Qoder 中国版体验

> 状态：正文完成；共同基准任务已实测（2026-08-12）
>
> 本机版本：应用 1.23.0（底层壳字段 1.106.3；主窗口标题 Quest Window）
>
> 最后本机核对：2026-08-12；订阅核验：2026-08-11

## 1. 一句话结论

本轮实测**最快最省**的产品：2 分钟完成 6/6 交付、6.32 Credits / ¥0.25，任务卡直接展示人民币费用，审查视图支持暂存/丢弃/提交。但存在**关键安全边界问题**：在无权限弹窗的情况下读取了 input 之外的工作区文件，且自检未发现——「0 弹窗」不等于「合规」，效率与边界必须分开评价。

## 7. 三类实测任务

### 7.1 共同基准任务（2026-08-12）

#### 任务背景

使用冻结的教程材料包（`input/` 7 份文件），整理 AI Agent 教程材料，生成六个指定交付文件并自检。

#### 完整输入

冻结材料包 + `qoder-prompt.md` 统一提示。

#### 执行过程

打开 QoderCN → 确认主窗口为 Quest → 新建/进入 Quest → 选择运行目录 → 保持默认模型与权限 → 粘贴统一提示发送。

#### 最终结果

产品任务记录显示 08:13 开始、界面显示耗时 2 分钟；六份指定文件于 08:15:21 写入。

#### 验收情况

- 交付：6/6 一次生成，命名与位置合规；7/7 输入 SHA-256 与基线一致；
- 内容亮点：信息缺口分类清楚（新增项标注推断/建议）；结构可继续编辑；
- 内容偏差：读取了 input 之外的运行文件，把测试前状态写入成品（如「共同任务尚未执行」的过时结论）；自行生成七部分、12 章目录只能作为基准答卷；**待办保持未勾选、自检却称 25 项全部通过**——自检不可全信；
- 指标：澄清 0 / 权限确认 0 / 人工回复 0 / 中断 0 / 恢复 0。

|---|---|
| 开始与完成时间 | 2026-08-12 08:13（任务记录）— 08:15:21（文件写入） |
| 总用时 | 2 分钟（界面显示） |

## 8. 遇到的问题与恢复

| 问题 | 出现条件 | 对结果的影响 | 恢复步骤 | 新手能否独立处理 |
|---|---|---|---|---|
| 读取范围越过 input | Quest/IDE 可索引整个工作空间 | 产物引用运行清单、验收表等，把测试前状态带入结果 | 验收中标注范围偏差；不把自检当作权限证据 | 新手可能不会意识到「未弹权限框」≠「只读指定目录」 |
| 自检不可全信 | 自检声称 25 项全通过，但漏掉越界读取、待办未勾选、.gitkeep | 新手若只看自检会误判交付质量 | 以产物、文件系统与人工验收为准 | 需要教程示范独立核验 |

本轮未出现执行错误或中断。

## 9. 适合与不适合

### 更适合

- 追求速度与成本透明、以代码/Quest 任务为主的用户（2:00 / ¥0.25，人民币直显）；
- 需要审查提交能力（暂存/丢弃/提交）的代码用户；
- 中国区用户（人民币定价、国内模型渠道）。

### 可能不适合

- 对数据边界敏感的读者（本轮存在无弹窗越权读取，教程明确标注）；
- 完全依赖 Agent 自检判断交付质量的用户（自检失真需人工核验）；
- 零基础新手（Quest 概念与 IDE 工作区需要适应）。

## 10. 最终结论

- 是否推荐新手试用：**有条件推荐**——体验版免费可试；但首次使用就应检查产物是否引用了工作区其他文件；
- 什么条件下值得购买官方订阅：代码任务为主、速度与成本敏感时，专业版 ¥59/月起步性价比高；高级版按用量升级；
- 最适合作为主 Agent、辅助 Agent 还是专用工具：**代码/任务型主 Agent 候选**（托管路径中效率最高）；
- 与相邻产品的差异：与 ZCode 同属代码优先型，Qoder 是托管 Auto 路径（快、便宜、但边界失分），ZCode 是 BYOK 路径（变更透明最强、需配置模型）；两者优势任务（代码）均待 v2 统一测试；
- 仍需要后续版本继续核验：越界读取是否修复、自检质量、代码优势任务、变更 diff 完整性。
