# Codex 桌面版体验

> 本机版本：26.803.10989.0；实测 2026-08-12；订阅核验 2026-08-11
>
> 测试条件：gpt-5.6-sol + 高推理强度 +「请求批准」权限配置，结论不推广到其他模型或权限组合。

## 1. 一句话结论

本轮六维评分中**综合交付一致性最佳**的产品：交付、预览、变更、过程、边界五个维度全满分，审阅视图与 Git 深度整合、支持审阅后直接提交推送。短板是客户端成本不透明、需自行查账单。适合项目型、代码与文档综合交付，且愿意检查变更的用户。

## 2. 关键事实

- **产品与版本**：Codex（OpenAI 官方 Windows 桌面应用），26.803.10989.0；窗口标题显示 `ChatGPT`、安装包名 `OpenAI.Codex`
- **账号与计费**：ChatGPT 账号，美元计费；随 Free / Go / Plus / Pro 等方案提供
- **入门分组**：海外闭源托管型综合 Agent；建议基础：零基础可用（检查变更需一点耐心）
- **运行方式**：云端（官方订阅路径）；自主程度：中—高（可配置请求批准）
- **官方更新日志**：桌面版无公开更新日志；Codex CLI 开源仓库最新开发线 rust-v0.148.0-alpha（08-13），与桌面版版本号体系独立

## 3. 订阅与计费

| 项目 | 内容 | 核验 |

**实测补充**：本轮客户端未清晰显示 Credits/Token/人民币成本（记录为「不可见」），不能与展示成本的产品（Qoder 等）直接比较。

## 4. 核心能力

- **已验证**：6 份 Markdown 成品一次生成；任务工作台、概览预览（渲染/源码切换）、审阅视图（分支对比、变更统计、逐文件 diff、提交或推送）；只读取 input 材料包，未发现越界读取
- **入口可见未实测**：拉取请求、站点部署、定时任务、Git/终端
- **新手路径**：新建任务 → 选择本地环境并打开工作目录 → 粘贴提示词 → 发送

## 5. 实测记录（共同基准任务）

- **结果**：6/6 交付一次通过，7/7 输入 SHA-256 与基线一致；总用时 5 分 45 秒；审阅视图显示 +7,822/-6（仓库全局统计）
- **介入**：人工 0 / 权限确认 0（配置「请求批准」但未触发——策略与触发是两回事）/ 中断 0 / 恢复 0
- **亮点**：信息缺口分类完整；生成目录恰为 23 章与正式框架章数一致（标题差异大，只能作修订参考）
- **注意**：`02-information-gaps.md` 生成后约 1 分钟发生一次后置修改（按最终版本验收，不推断为重试；无界面证据时新手难判断何时真正稳定完成）
- **边界**：优势任务（文档+代码+网页交付物）、边界任务（权限不足/中断恢复）待 benchmark v2 统一测试

## 7. 适合与不适合

**适合**：项目型工作（代码、文档、多步骤交付一次完成）；愿意检查变更的用户（逐文件 diff + 提交推送）；已有 ChatGPT 订阅的用户（零额外学习成本）。

**不适合**：只需要简单问答的用户（工作台形态偏重）；无法提供项目权限或验收条件的人；要求客户端内透明显示费用的用户（本轮成本不可见）。

## 8. 最终结论

- **推荐新手试用**：从 Free 档轻量任务开始；前提是账号与支付可用
- **定位**：**综合交付型主 Agent 候选**（托管路径中综合一致性最佳）；需要持续项目交付与变更审阅时 Plus 及以上价值明显
- **与相邻产品差异**：同属海外综合型，比 Claude 本轮有完整实测数据；与 ZCode 是托管订阅 vs BYOK 路径差异，审阅体验同级但无需自行配置模型
- **待核验**：客户端成本透明化、代码优势任务、恢复场景完整截图、全新安装路径复测
