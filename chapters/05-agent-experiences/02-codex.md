## 1. 一句话结论

适合希望用同一个桌面工作台处理项目、代码、文档和多步骤交付的用户，但价值需要结合官方账号、订阅用量、项目权限和验证能力判断。

- 账号、套餐与地区状态在正式测试记录中补齐。

## 3. 下载、安装与首次启动

记录 Windows 安装入口、官方登录、工作区选择和首次权限提示。当前客户端正用于本教程项目，首次全新安装路径仍需单独复测。

## 4. 免费额度、订阅与计费

区分 ChatGPT 套餐内用量、追加 Credits 和 API Key 的 Token 账单。默认测试官方订阅，不用第三方切换工具替代官方体验。

## 5. 核心能力

重点测试项目理解、文件修改、命令与工具调用、Git、终端、文档处理、视觉交付和结果验证。

## 6. 界面与工作方式

当前形态是任务侧栏、对话工作区与项目工具结合的桌面工作台。截图需解释包名与窗口标题差异，并展示过程而不只展示最终回复。

## 7. 三类实测任务

### 7.1 共同基准任务

使用冻结的教程材料包，生成六个指定交付文件并自检。

### 7.2 优势任务

候选：从资料和现有仓库生成一组文档、代码与网页交付物，并完成验证。

### 7.3 边界任务

测试权限不足、任务中断、上下文过长或外部服务不可用时的恢复过程。

## 8. 遇到的问题与恢复

记录任务中断、工具失败、权限提示、工作区选择错误、变更回退和重新验证。

## 9. 适合与不适合

更适合项目型工作和愿意检查变更的用户。可能不适合只需要一次简单问答，或无法提供项目权限与验收条件的人。

## 10. 最终结论

待共同、优势和边界任务完成后判断是否适合作为主 Agent，以及哪个官方订阅档位值得购买。
