# 本机桌面客户端与界面核对记录

> 核对日期：2026-08-12（Asia/Shanghai）
>
> 核对方式：读取本机安装信息，并实际打开桌面客户端观察可见界面。
>
> 使用边界：只查看，不发送任务、不修改设置、不代为登录，也不执行项目初始化。

## 1. 为什么要保留这份记录

官方文档能说明功能和价格，但不能替代作者实际看到的桌面体验。本记录用于固定写作时的产品线、客户端版本、界面结构和命名差异，避免把国际版、中国版、Work 产品线或底层壳版本混在一起。

本记录不是正式产品评测。界面会随版本更新，正式截图和体验结论仍需在产品页中注明测试日期。

## 3. 必须严格区分的产品线

### Qoder

本机同时存在：

- `QoderCN`：教程中的 Qoder 中国版代码优先型 Agent；
- `Qoder`：国际版；
- `QoderWork CN`：另一条 Work 产品线，历史新人和学生 Credits 活动属于这里。

三者不能共享价格、福利、截图和版本结论。

### Trae

本机同时存在：

- `Trae CN`：代码开发环境；
- `TRAE SOLO CN`：实际窗口显示为 TraeWork CN，是教程中的综合型 Agent。

教程的 TraeWork 页面不得用 Trae CN 的模型配置或 IDE 截图替代。

## 4. 实际界面形态

### Claude

当前只能观察登录前欢迎页：大面积白色留白、中央橙色标志、`Claude for Windows` 标题和底部黑色 `Get started` 按钮。作者账号已经被封，因此登录后的主工作区、实际免费额度和完整任务流程均标记为待验证。

写作重点不是推测封号原因，而是记录：账号可用性会直接阻断桌面体验，能力和订阅价格不能替代账号稳定性判断。

### Codex

当前桌面端采用任务与项目协作形态，而非单一聊天窗口。教程应围绕任务侧栏、对话工作区、项目上下文、文件变更、Git、终端和验证过程截图。

当前 Windows 包的清单显示名称和窗口标题为 `ChatGPT`。截图图注应明确这是 Codex 桌面包的当前构建，避免读者误认为核对了另一个产品。

### TraeWork 中国版

左上直接提供 `Work / Code / Design` 三种模式。左侧还有新建任务、插件市场、设计系统、办公助理和任务列表；中间以任务过程、消息和产物卡片为主，底部是统一输入区。

因此产品页应按三种模式组织体验，而不是只用“中文办公 Agent”概括。

### WorkBuddy

登录后的 5.3.11 主界面包含：

- 左侧的新建任务、助理、项目、专家/技能/连接器、自动化、资料库和更多应用；
- 中间的日常办公、代码开发、设计创意三类场景；
- 文档处理、金融服务、数据分析与可视化、个人工作台、深度研究、视频生成、幻灯片和产品管理等入口；
- 支持 `@` 引用文件或对话、使用 `/` 调用技能与指令，并选择工作空间和权限；
- 右侧概览、产物和引用来源。

本次账号界面显示“今日可领 100 积分”，属于带日期和账号条件的客户端可见活动，不直接写成长期固定福利。

### Qoder 中国版

界面以 `Quest` 为主要任务单位。左侧按工作区组织 Quests 与 Chats，并提供定时任务、Better Harness、知识中心、插件市场、账号与额度入口；中间是任务对话；任务产物提供概要、终端、文件、审查和浏览器快捷入口。

它虽然属于代码优先型，但当前形态已经接近 Agent 项目控制台，不应只描述为带 AI 的代码编辑器。

### ZCode 中国版

左侧按分组和项目管理任务，顶部提供新建任务、搜索、自动化与技能；中央输入区能够选择项目、权限模式、模型和推理强度，并展示闲时任务模板；底部提供终端入口。

它的核心界面也是任务管理工作台。产品页需要同时评价代码能力和任务组织能力。

### Hermes Desktop

当前为成熟的三栏工作台：

- 左侧：新建会话、技能与工具、消息平台、产物、项目和 Profiles；
- 中间：会话、分支、上下文、模型选择和语音功能；
- 右侧：项目文件树和终端；
- 顶部：布局编辑器、HUD 模式和侧栏控制。

“极客型”应解释为模型接入、配置自由度、权限、环境和维护责任更高，而不是界面粗糙或没有 GUI。

## 5. 对教程截图的直接要求

- 截图前隐藏账号名称、历史任务、项目名称、本地绝对路径和额度信息；
- 同一产品分别保存登录前、首页、任务过程、权限确认、产物和失败恢复截图；
- Qoder、TraeWork 和 WorkBuddy 的截图标题必须写清具体产品线；
- 版本号优先采用客户端内“关于”页面或当前可执行文件信息，不直接采用可能过期的卸载注册表；
- 界面观察只证明“当时看到了什么”，不自动证明功能长期可用或所有账号都有相同权益。
