## 为什么用「整体优先」

新手面对 Agent 桌面端时，最难的往往不是某个按钮，而是「这个界面由哪几块组成、每块是干什么的」。因此每款产品只保留 2–3 张关键截图，先看整体布局，再进入概览/预览、变更/审阅等具体环节，避免把界面切碎后反而看不懂。
